# SoSmartButNeverPunctual

Python script (`punctual.py`, stdlib only, Python 3.9+) that keeps Samsung
appliance clocks in sync via the SmartThings API, plus a bare-bones Tkinter window
(`punctual_gui.py`, `theming.py`, `updater.py`) packaged with PyInstaller. See `README.md`.

- `punctual.py` must stay standalone: it must never import `punctual_gui` or
  `tkinter`, so people can download that one file and run it headless.
- The Debian package (`release-deb.yml` from KVG_Standards, wired in `auto-release.yml`/`cut-release.yml`)
  installs **only `punctual.py`** plus `_version.py`. So `punctual.py` must never import another file from
  this repo or a third-party package. A new runtime file would have to be added to `install_files` in both
  workflows, and the workflow's smoke test (installed command must report the tag's version) is the drift guard.
- Runs on Windows, macOS and Linux. Scheduling is Task Scheduler on Windows and
  crontab elsewhere.

This repo follows [KVG_Standards](https://github.com/gerp93/KVG_Standards)
(AGPL-3.0 `LICENSE`, `TODO.md`, branch + PR for every change, merged without
asking per the owner's global rules). It is a PyInstaller desktop app per the standards:
VisualAssault theme (pinned tag), `kvg_updater`, logo/icons generated by `scripts/`,
`auto-release.yml` + `cut-release.yml` (every push to `main` ships a release, so every
merge publishes one), `VERSION_BUMP.md`.

- The packaged exe doubles as the scheduled job: `punctual_gui.main` runs `punctual.main()`
  when given arguments (e.g. `sync`), with no window. Don't break that path.
- Bump the VisualAssault pin in `requirements.txt` in its own commit and re-test the theme picker.

- Tests: `python -m unittest discover -s tests -v`
- Keep it dependency-free and public-friendly: nothing specific to the owner's
  devices, network or accounts goes in the repo. Tokens live outside the repo.
- Refresh tokens are single-use: save new tokens immediately after any refresh,
  and keep runs serialized by the lock.
- The clock command (`/configuration/vs/0`, `x.com.samsung.da.currentTime`) is
  undocumented; treat any change in its behavior as a Samsung-side break.
